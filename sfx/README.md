# Recorded sound effects (optional)

The game synthesises all of its voices (screams, falling screams, cackling, sobbing, whispering, muttering,
humming, a far-off thud). If a recording is published next to the page in this folder, it is played instead.

Name files like this (Ogg Vorbis); up to three variants each, picked at random:

    scream.ogg  scream2.ogg  scream3.ogg
    fallscream.ogg   laugh.ogg   sob.ogg   whisper.ogg   hum.ogg   thud.ogg

Only use sounds you are allowed to ship. CC0 (public domain) candidates on OpenGameArt:

- Maniacal Laughter Pack 1 — https://opengameart.org/content/maniacal-laughter-pack-1
- Evil Laugh — https://opengameart.org/content/evil-laugh
- Evil Laugh 2 — https://opengameart.org/content/evil-laugh-2
- 80 CC0 creature SFX (includes screams) — https://opengameart.org/content/80-cc0-creature-sfx
- Horror Hit Soundpack 1 — search OpenGameArt for it (55 CC0 jumpscare hits)

Check each download's own license file before including it.
